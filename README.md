# Jaga Comments Toggle

Расширение для таск-трекера "Яга". Работает только на `https://jaga.rt.ru/*`.
Расширение позволяет скрывать правую секцию с комментариями на странице текущей задачи, а так же восстанавливать описание задачи из временного хранилища при включении настройки `"Сохранять черновики описания"` (экспериментальная функция, по умолчанию выключена). 

## Скрытие секции комментариев к задаче
При скрытии комментариев применяются только эти изменения:

```css
[data-class="EditCard_wrapper"] {
  flex-direction: column !important;
}

[data-class="EditCard_formColumn"] {
  width: 100% !important;
}

[data-class="EditCard_modulesColumn"] {
  display: none !important;
}
```

Дополнительно только у третьего по порядку элемента (секция с описанием задачи) `[data-class="AttributeWrapper_wrapper"]` устанавливается:

```css
flex-direction: column !important;
```

При повторном нажатии все эти изменения отменяются.

## Сохранение черновиков описания

Опциональная экспериментальная функция для автоматического сохранения несохраненных изменений (черновика) в описании текущей задачи.
После включения функции расширение отслеживает изменения только в поле `Описание` и сохраняет текущую версию во временное локальное хранилище браузера.
Если после закрытия вкладки, перезагрузки страницы или разлогина в описании остались несохранённые изменения, при следующем открытии редактора появляется предложение восстановить черновик.

Доступные действия:

- `Восстановить описание` - заменяет текущее содержимое редактора сохранённой версией. Если после вставки что-то пошло не так, в самом редакторе можно нажать `CTRL + Z` для отмены изменений.
- `Удалить черновик` - удаляет сохранённую версию без восстановления.

Черновики сохраняют форматирование текста, включая списки, заголовки, ссылки и другие элементы редактора.

Функция отключена по умолчанию и включается через настройки расширения:

`Сохранять черновики описания (experimental)`

Хранится до 20 последних черновиков.

## Установка

1. Распакуйте архив `yaga-extension.zip` из свежего [релиза](https://github.com/kpako3rbp/yaga-extension/releases).
2. Откройте `chrome://extensions/`.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение».
5. Выберите папку `yaga-extension` из распакованного архива.
6. Откройте или обновите страницу `https://jaga.rt.ru/browse/TASK-123`.
